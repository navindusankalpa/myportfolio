VisionAgri AI is a web-based diagnostic platform for smallholder farmers that classifies chili pepper and tomato leaf diseases, quantifies infection severity, and delivers context-aware guidance through a production-ready cloud deployment.

About This Project

A production-oriented diagnostic system built for resource-constrained agricultural settings.

Project Overview

VisionAgri AI combines multi-task deep learning with cloud deployment to classify diseases and quantify infection severity in chili pepper and tomato leaves. The system pairs an EfficientNetV2-B0 backbone with a lightweight MobileNetV3-Small segmentation alternative, while a MobileNetV2 gatekeeper filters out-of-scope uploads before inference.

Context-aware recommendations are generated by integrating the Open-Meteo weather API and an OpenRouter-hosted large language model, and the full stack is containerized with Docker on visionagri.app to support practical use in low-resource farming environments.
